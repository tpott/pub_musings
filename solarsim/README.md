# solarsim

May try simulating some solar arcs or solar reflector characteristics.

I found [Scheffler- Reflectors](http://www.solare-bruecke.org/index.php/en/die-scheffler-reflektoren)
to be interesting. Specifically, the design uses a lateral cut of a parabola, rather than a full
parabolic reflector.

Basic math for a parabola: `4 * a * f = r ** 2`

Hoping to use https://stemkoski.github.io/MathBox/index.html but d3js is a also a classic.
