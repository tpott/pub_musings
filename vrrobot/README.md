# vrrobot

## Setup

Run `npm install puppeeteer` once you have `node` and `npm` setup. If you don't
have those yet, follow the `nvm` instructions for doing so:
https://github.com/nvm-sh/nvm?tab=readme-ov-file#installing-and-updating
once you do, the following commands should all work:
* `command -v nvm` should resolve to `nvm`
* `node -v` should resolve to the version you installed with nvm
* `npm -v` should resolve to the expected version

Now you can run `node vdo-connect.js`!
