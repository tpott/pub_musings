## Implementing

When you are implementing a new feature, project, or plan, please do not run
commands that have side effects. For example, do not run `npm install` nor
`pip install`.

Additionally, you should avoid running commands that depend on environment state.
For example, many python commands assume you have source'd the venv activate script
to make your execution environment correct. Please ask me to run a command for you
unless I have explicitly asked you to run a command.
